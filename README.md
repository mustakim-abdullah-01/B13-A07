# 🌿 Keen Keeper

> **Friends to keep close in your life**

Keen Keeper is a personal friendship management web application that helps users maintain meaningful connections. Users can browse their friends, view detailed information, track interactions, and monitor their communication history.

## ✨ Key Features

### 👥 Friend Management

Browse a dynamic list of friends and view detailed information about each connection, including their status, tags, bio, contact goal, and next due date.

### 🕒 Interaction Timeline

Record **calls, texts, and video calls** with friends. Each interaction is added to a timeline with the date it occurred.

### 📊 Communication Statistics

View communication activity through an interactive **pie chart**, showing the total number of calls, texts, and video calls using Recharts.

### 🔔 Action Notifications

Get instant **toast notifications** when performing actions such as Snooze, Archive, or Delete.

### 📱 Responsive Design

Enjoy a clean and responsive interface that adapts smoothly across **desktop, tablet, and mobile devices**.
